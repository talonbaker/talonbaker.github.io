# Blueberry — temporary test build

A Godot 4.7.1 Web export of **Blueberry**, parked here only because GitHub
Pages is not yet enabled on its own repository.

**This is temporary.** Once the project has its own Pages site, this folder
should be deleted and test builds will never be published here again.

Single-threaded Web export (`web_nothreads_release`) — the threaded export
needs COOP/COEP headers GitHub Pages cannot serve.

See `build-info.json` for the exact commit this was built from.
