Bike — DocFX Documentation Site

This directory contains the source for the Bike project documentation site, generated by DocFX.

The site includes:

  • API reference — auto-extracted from C# XML doc comments on Bicycle.Physics and Bicycle.World
  • Conceptual articles — architecture, Whipple model math, gotchas, phase history, glossary
  • Full-text search via lunr.js (DocFX built-in)

Install DocFX

dotnet tool install -g docfx

Requires .NET 8 SDK or newer.

Build the site

From the repo root:

docfx docs/docfx/docfx.json

Output is written to docs/docfx/_site/ (gitignored — build output, not source).

Serve locally

docfx docs/docfx/docfx.json --serve

Opens the site at http://localhost:8080.
