Phase History

A chronological record of completed milestones with what they shipped and where they live.

Phase 1: Physics Core

Status: Done — merged to main GitHub: [Epic closed — see PR history for individual stories]

What shipped:

  • Bicycle.Physics library — pure C#, .NET Standard 2.1, allocation-free
  • BicycleSimulator — single-bike integrator with RK4 at 250 Hz
  • BicycleParameters — POD geometry + inertia with MeijaardBenchmark and GameDefault presets
  • BicycleState, BicycleSnapshot, BodyPose, ControlInputs — full public API surface
  • ParametersJson — Save/Load helpers
  • WhippleEOM.cs + WhippleKinematics.cs — generated from SymPy + PyDy + Kane's method
  • 42 xUnit tests: eigenvalue benchmark, allocation-free gate, determinism gate, behavioral scenarios

Key results:

  • Eigenvalues match Meijaard 2007 Table 2 to 6 decimal places
  • Zero managed-heap allocations in Step() — CI-gated
  • ~3 µs/step on i7-13700K

Spec: docs/superpowers/specs/2026-05-09-bicycle-physics-core-design.md

Phase 2: Unity MVP

Status: Done — merged to main GitHub: [feat/bicycle-unity-integration]

What shipped:

  • Unity 2022.3 LTS integration — Bicycle.Physics consumed as a local Unity package
  • Sandbox.unity scene — color-coded primitive bicycle, press Play and ride
  • BicycleController — FixedUpdate tick, 250 Hz physics, interpolated rendering in Update
  • DebugInputProvider — WASD/arrow keyboard controls with documented sign-convention workarounds
  • BicycleVisualizer — four-body pose-driven primitive geometry
  • ChaseCamera — smooth follow camera
  • HUD — forward speed, roll, steer debug overlay
  • Auto-reset on fall (|Roll| > 1 rad or NaN)
  • BicycleRagdoll — visible fall cinematic (rider limbs via CharacterJoint chain)
  • Fixed yaw sign bug in kinematics (Gotcha 15)

Spec: docs/superpowers/specs/2026-05-10-bicycle-unity-integration-design.md
